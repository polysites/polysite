# How it works, in diagrams

Four interactive diagrams of the parts people ask about most. Each opens in its own tab, works on a phone (pinch to zoom, tap a step for detail) and has a Live / Still switch for the animation.

| Diagram | What it shows | Read next |
| --- | --- | --- |
| <a href="../diagrams/publishing.html" target="_blank">Page publishing lifecycle</a> | A page from draft to live: review, schedule, save draft on a live page, unpublish | [Drafts and publishing](/guide/publishing) |
| <a href="../diagrams/petition.html" target="_blank">Form and petition signature</a> | What happens between a visitor pressing submit and the thank-you: server checks, one signature per person, the public count | [Forms and sign-ups](/guide/forms) |
| <a href="../diagrams/agent.html" target="_blank">AI agent over MCP</a> | How a key connects an agent, why the key's own role decides what it may do, and where a draft stops | [AI agents plugin](https://github.com/polysites/polysite-plugins/tree/main/mcp) |
| <a href="../diagrams/deploy.html" target="_blank">Safe deploy</a> | The steps `deploy/deploy.sh` takes, in order, and what puts the old version back | [Deploying](/guide/deploying) |

The diagrams show behaviour as built today. When a guide and a diagram disagree, the guide and the code win; please open an issue so the diagram is fixed.
